# Daily Coding Practice

This repository is my personal space for practicing programming and improving my coding skills every day.

I use it to solve small problems, experiment with ideas, and build a stronger understanding of the programming languages I know. I am starting with JavaScript and will add more languages and exercises over time.

## Current Focus

### JavaScript

The JavaScript practice files contain beginner-friendly problems and solutions, including:

- Reversing a string
- Finding the longest word in a sentence

Current exercises: [js/firstday.js](js/firstday.js)

## Goals

- Practice consistently on a daily basis
- Improve problem-solving and logical thinking
- Strengthen JavaScript fundamentals
- Learn and practice additional programming languages
- Keep track of progress through working examples

## Running the JavaScript Exercises

Make sure Node.js is installed, then run:

```bash
node js/firstday.js
```

As this repository grows, new exercises will be organized by language and practice day or topic.
